# Карточки знания

Пиши домашнюю карточку: факт в мире, не разбор вопроса.

Формат одной строки: `вещь — суть`.
Обычно одна строка. Две — только если в вопросе два независимых факта (дуплет, два разных имени).

Хорошо:
- `даман — мелкий зверёк, ближайший ныне живущий родич слона`
- `Гретна-Грин — шотландская деревня у английской границы, куда ехали венчаться без согласия родителей`
- `теломеры — концевые участки хромосом, с возрастом укорачиваются`

Плохо:
- голое имя: `Борхес`
- как взять вопрос: `каламбур Rex Stout / T. rex stout`
- зеркало из формулировки (если Арджуна уже в тексте — пиши про Гамлета)
- абзац из комментария, сленг, «в вопросе», «замена», «ИКС»

Выход: JSON-объект `{ "question_id": ["фраза"] }`. Все id из входа должны быть.
Файл: рядом, `batch-NNN-cards.json`.
